WILDLANDS ONLINE STARTUP ERROR TRACE

This is a diagnostic replacement for index.html, not a guaranteed final fix.

1. Back up your current index.html in GitHub.
2. Replace it with this index.html.
3. Commit and push to trigger Render deployment.
4. Reload the site and note the full startup error message.

This package does not include package.json or server.js because this change is limited to the browser page.
